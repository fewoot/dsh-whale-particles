DSH 鲸鱼点阵背景 · 离线安装包
================================

给另一台装好 DSH Desktop 的电脑离线安装本插件。

【方法一:双击安装(推荐,无需命令行知识)】
1. 解压 dsh-whale-particles-offline-*.zip,把整个文件夹(连同 dsh-whale-particles\ 子目录和两个 .bat)拷到对方电脑,或用 U 盘拷过去;
2. 让对方双击 install-whale.bat;
3. 看到"安装完成"后重启 DSH Desktop。

【方法二:手动复制(想了解原理时)】
1. 把 dsh-whale-particles 文件夹整个复制到:
     C:\Users\<对方用户名>\.dsh\profiles\desktop\node_modules\dsh-whale-particles
2. 编辑(先备份)同一目录下的 package.json,把 "dsh-whale-particles" 加进
   dsh.profile.bundles 列表(参考已装机器上的写法);
3. 重启 DSH Desktop。

【注意事项】
- profile 名:默认 desktop;如果你的 DSH 用的是别的 profile(web 等),
  请用 `install-whale.bat <profile名>` 指定。
- 版本适配:本包(0.4.1)的界面类名哈希对应 DSH Desktop v2.0.5(web 0.1.2-rc.1)
  及更新的 v2.0.9(web 0.1.5-rc.1),二者实测同为 `_1qAH1q` / `uPhUma`。
  若对方是更早的 v2.0.3(web 0.1.1-rc.2),背景透明与"空会话输入栏下移"会失效
  (点阵照常渲染,但会被界面盖住),需按插件 README 的对照表换回旧前缀。
- 卸载:双击 uninstall-whale.bat,或在 设置 -> 插件 里停用/删除。
- 插件自身设置(localStorage)存在对方自己浏览器里,拷贝不会带过去;照片蒙版同理,需各自导入。

文件内容说明:
  dsh-whale-particles/  插件本体(免构建,含 lib/client.js)
  install-whale.bat/.ps1   一键安装(自动备份 package.json)
  uninstall-whale.bat/.ps1 一键卸载
